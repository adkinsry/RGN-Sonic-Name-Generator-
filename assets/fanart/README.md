Drop fan-art images here (PNG, JPG, WebP or GIF), then run `npm run embed-assets`.
Only use pieces you have the artist's permission to use, and credit them in `credits.json`:

    { "kevin.png": { "caption": "Kevin the Shrimp", "credit": "art by @someone" } }

Square-ish images about 400 px wide keep index.html small.
